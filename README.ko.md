# Godot UI Exporter 1.1

Figma에서 선택한 화면/레이어의 이름과 추출 리소스를 한 화면에서 정리하는 로컬 개발 플러그인입니다.
API 키, 서버, MCP 연결, npm 설치, 빌드 과정이 필요하지 않습니다.

## 1. 설치

1. ZIP을 압축 해제합니다. `manifest.json`, `main.js`, `ui.html`을 같은 폴더에 두세요.
2. **Figma 데스크톱 앱**에서 디자인 파일을 엽니다.
3. 메뉴 **Plugins → Development → Import plugin from manifest…**에서 이 폴더의 `manifest.json`을 선택합니다.
4. **Plugins → Development → Godot UI Exporter**를 실행합니다.

Figma 버전/설정에 따라 manifest의 plugin ID를 요구하면:

- **Plugins → Development → New plugin…**에서 UI가 있는 플러그인을 하나 만듭니다.
- Figma가 만든 manifest의 `id` 값을 이 패키지의 manifest에 추가합니다. 다른 속성은 유지합니다.
- 임의의 Community 플러그인 ID를 복사하지 마세요. 본인이 만든 ID를 사용합니다.

이 패키지는 로컬 개발 플러그인입니다. Community에 게시하거나 계정에 자동 설치하지 않았습니다.

## 2. 네이밍과 추출

1. Figma 레이어 패널에서 `Godot2`처럼 작업할 화면/상위 레이어 **하나**를 선택합니다.
2. 하위 요소의 원본 이름, 리소스 이름, 기준 크기, 추출 방식, 공통 후보를 확인합니다.
3. 리소스 이름을 수정합니다. 예: `button_start`, `icon_settings`, `panel_inventory`.
4. 실제 Figma 레이어명도 바꾸려면 **레이어 이름에도 적용**을 체크하고 **이름·설정 저장**을 누릅니다.
5. PNG 배율을 고른 뒤 **전체 ZIP 내보내기**를 누릅니다.

설정은 각 노드의 plugin data에 저장됩니다. 이름·분류·추출 방식을 수정한 뒤 저장해야 다음 실행에도 유지됩니다.
내보내기만 누르면 현재 창의 설정을 사용하며 설정을 파일에 저장하지는 않습니다.
이름 저장은 숨겨진/부모에 포함된 항목도 포함합니다. 실제 이름 변경을 체크하지 않으면 원본 레이어 이름은 유지됩니다.
원본 이름 변경 후 되돌리려면 즉시 Figma Undo를 사용하세요.

### 자동 이름의 범위

- 버튼/아이콘/패널/배경/로고 등 명칭 힌트로 역할 접두사를 제안합니다.
- 영문 이름은 소문자와 밑줄로 정리합니다.
- `Rectangle 123`, 한글 전용 이름 등 의미가 불명확한 항목은 노드 유형과 ID를 이용한 임시 이름을 사용합니다.
- 이미지를 보고 의미를 판단하는 AI는 포함하지 않습니다. 이름 칸에서 용도를 직접 지정할 수 있습니다.
- 이름은 영문 소문자 또는 숫자로 시작하며 소문자·숫자·밑줄만 허용합니다(최대 96자). 같은 분류 내 이름 충돌은 내보내기 전에 차단합니다.

### 추출 방식

추출 범위의 기본값은 **개별 리소스**입니다. 최상위 화면은 native로 두고, 한 장으로 묶을 하위 부모를 PNG/SVG로 지정하세요. PNG/SVG 부모 하나당 자식 전체를 합성한 파일 하나를 출력하며, 그 아래 자식은 별도 파일로 출력하지 않습니다. 더 세분화하려면 해당 부모를 native로 바꾸고 하위 묶음을 지정하세요.

Group은 합성 PNG를 기본 추천하며 직접 저장한 방식은 유지됩니다. Figma Export 설정이 있는 노드도 합성 추출 대상으로 인식하며 첫 설정이 SVG이면 SVG, 그 외 형식이면 PNG를 추천합니다. 선택한 화면 전체를 합성할 때만 **선택 전체 한 장**을 사용하세요. 이 옵션은 부모 방식이 SVG이면 SVG 한 장, 그 외에는 PNG 한 장을 출력합니다. 배율과 출력 경계는 이 도구의 설정을 사용합니다.

| 방식 | 용도 | 출력 |
|---|---|---|
| PNG | 이미지, 아이콘, 복잡한 효과/마스크/회전 | 투명 배경을 유지하는 합성 PNG |
| SVG | 단순 벡터 | 텍스트 윤곽선 포함 SVG, Godot 호환 확인 필요 |
| native | 텍스트, 단색 패널, 레이아웃 구조 | JSON, Label/Panel 배치 초안 |
| 제외 | 장식/불필요한 요소 | 해당 노드와 하위 전체 제외 |

- PNG/SVG를 선택한 부모의 자식은 **부모에 포함**으로 표시되고 중복 추출되지 않습니다.
- 부모도 PNG로 받고 자식도 개별적으로 필요하면, 부모 추출 후 자식을 따로 선택해 한 번 더 추출하세요.
- 자동 추천은 규칙 기반입니다. 복잡한 프레임은 외형 보존을 위해 PNG로 추천하므로, 자식 개별 추출이 필요하면 부모를 native로 바꿔 주세요.
- 숨김 레이어는 추출하지 않습니다.
- 공통 후보는 선택 범위 안의 반복된 컴포넌트 연결을 기준으로 표시합니다. 자동으로 공통 분류로 확정하지 않습니다.
- **공통 후보 표시 적용**은 후보의 분류를 공통으로 바꿉니다. 동일 리소스인지 확인한 뒤 저장하세요.
- 공통 폴더 분류와 Godot 공통 씬 제작은 별개입니다. 공통 씬은 자동 생성하지 않습니다.
- **선택 고정**을 켜면 Figma에서 다른 레이어를 눌러도 분석 대상을 유지합니다.
- 열린 상태에서 디자인을 수정했다면 **다시 분석**을 누르세요. 내보내기 직전에도 최신 속성을 다시 읽습니다.

## 3. ZIP 내용과 Godot 적용

ZIP에는 다음 파일이 들어 있습니다. 실제 폴더 이름은 선택한 노드 ID로 정해집니다.

- `figma_ui/screen_n_…/assets/shared/`: 공통으로 분류한 이미지
- `figma_ui/screen_n_…/assets/screen/`: 화면 전용 이미지
- `manifest.json`: 노드 ID·부모 관계·좌표·논리 크기·실제 PNG 크기·스타일·리소스 경로
- `resources.csv`: 리소스 목록(Excel에서 열 수 있는 UTF-8 BOM CSV)
- `generated.tscn`: Godot 4 시각 배치 초안
- `README.ko.md`: 해당 화면의 사용 안내와 필요한 폰트 목록

1. 내보낸 ZIP을 풉니다.
2. **figma_ui 폴더 전체**를 Godot 4 프로젝트 루트, 즉 `project.godot`가 있는 폴더로 복사합니다.
3. Godot의 이미지 가져오기가 끝나면 `generated.tscn`을 엽니다.
4. 폰트 파일과 Theme를 지정하고 버튼 동작, Container, 앵커, 9-slice를 적용합니다.

`generated.tscn`은 고정 기준 크기의 편집 가능한 초안입니다. 클릭 동작, 반응형 레이아웃, 자동 9-slice, 공통 PackedScene 생성은 포함하지 않습니다.
표시용 노드는 mouse_filter=IGNORE입니다. 상호작용이 필요한 버튼은 Button/TextureButton 등으로 구성하세요.
원본의 Auto Layout 설정은 JSON에 기록되지만 Godot Container로 자동 변환하지 않습니다.
재추출할 때 생성 씬은 덮어쓸 수 있으므로, 게임 로직은 별도 씬 또는 상속 씬에 작성하세요.

## 4. 사이즈가 달라지는 문제를 줄이는 원칙

- PNG의 픽셀 크기와 UI의 논리 크기를 별도로 기록합니다.
- 100×40 요소를 2×로 내보내면 PNG는 약 200×80, Godot Control은 100×40입니다.
- `TextureRect.expand_mode=IGNORE_SIZE`를 사용해 텍스처의 원본 픽셀이 Control의 최소 크기를 강제로 바꾸지 않게 합니다.
- 화면 레이어 이름을 바꿔도 노드 ID 기반 출력 폴더는 유지됩니다.
- 이미지 hash가 같아도 다른 크롭/크기의 노드이면 각각 내보냅니다.
- 고정 경계(`useAbsoluteBounds=true`)로 추출합니다. 경계 바깥 그림자·블러까지 필요하면 그 여백을 포함한 Frame으로 감싼 뒤 추출하세요.
- 선택한 노드가 바뀌면 출력 폴더도 바뀝니다. 기존 화면을 복제하면 새 노드이므로 새 화면으로 취급합니다.

## 5. 정확도와 제한

- 텍스트는 native Label에서 첫 텍스트 스타일만 적용합니다. 폰트 파일, 혼합 서식, 자간, 행간, 줄바꿈, 대소문자 변환은 Godot에서 확인해야 합니다. 정확한 외형이 우선인 고정 글자는 PNG로 선택할 수 있습니다.
- generated.tscn은 Figma 순서대로 그리는 평면 배치입니다. 원래 부모 구조/Auto Layout 정보는 manifest에 따로 보존합니다.
- 클리핑·마스크·회전·그룹 불투명도는 부모 PNG로 추천합니다. 이를 native로 강제로 바꾸면 배치 초안 외형이 달라질 수 있습니다.
- 배경 의존 혼합 모드는 배경을 포함한 부모까지 함께 추출해야 할 수 있습니다.
- SVG 필터/마스크는 Godot 렌더러와 차이가 날 수 있어 PNG가 기본입니다.
- 폰트 파일을 자동 다운로드하거나 포함하지 않습니다.
- 최대 5,000개 노드/이미지 합계 100MB/이미지 한 변 16,384px로 제한합니다. 큰 화면은 나눠서 추출하세요.
- 일부분에 오류가 나면 새 ZIP을 만들지 않고 오류를 표시합니다. 취소는 진행 중인 Figma 이미지 렌더가 완료된 후 반영됩니다.
- Figma를 열고 선택한 레이어에 접근할 수 있어야 합니다. 이 도구의 로직 자체는 외부 네트워크 요청을 하지 않습니다.

## 6. 검증 상태

이 패키지에서 실행한 검증:

- JavaScript 구문 검사
- Figma API 모의 환경: 선택 변경, 이름 저장/실제 이름 변경, 설정 재로딩, 공통 후보 표시
- 같은 이미지 원본을 쓰는 서로 다른 노드의 개별 추출
- 부모 합성/숨김/제외 처리, 중복 이름 차단, 오래된 선택 차단, 취소
- 2× PNG 픽셀 크기와 논리 크기 분리, 씬 리소스 경로
- ZIP CRC/구조와 PNG 파일 헤더 검증

실제 사용자 Figma 파일에서의 실행과 Godot 엔진 실행은 이 환경에서 확인하지 못했습니다.
브라우저 테스트 스크립트도 포함했지만 현재 실행 환경에 Chromium이 없어 시각 검증은 수행하지 못했습니다.

테스트를 다시 실행하려면 Node.js 18 이상에서 `node tests/test.cjs`를 실행하세요.
`tests/ui.cjs`는 Playwright와 Chromium이 설치된 환경에서 별도로 실행할 수 있습니다.
